These are existing Pianomania game UI font assets reused by Composer.

- Inter regular and medium: `Assets/Fonts/UI/Inter/Inter_24pt-Regular.ttf` and `Inter_24pt-Medium.ttf`; license included in `Inter-OFL.txt`.
- Barlow Condensed extra bold italic: `Assets/Fonts/UI/BarlowCondensed/BarlowCondensed-ExtraBoldItalic.ttf`; license included in `Barlow-OFL.txt`.

The fonts retain their SIL Open Font License. Inter is used for controls and song titles; Barlow is used for DR and action labels.
